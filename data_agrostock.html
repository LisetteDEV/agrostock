3. Paiement test ( simulation )

le paiement est en simulation, aucun de API de paiement n'est connecté. Pour le choix du mode de livraison , veuillez choisir " Livreur propre" car les fonctionnalités de "besoin d'un livreur" seront implémentées après la soutenance.

6. Scénarios de test suggérés

  1. Se connecter en tant que transformateur → publier un produit → recevoir des commandes → valider les commandes.
  2. Se connecter en tant qu'acheteur → commander ce produit → choisir "livreur propre" comme mode de livraison et payer→ remettre le code OTP au livreur →suivre la commande → confirmer la réception après avoir reçu la commande → Laisser un avis .
  3. Se connecter en tant qu'admin → consulter la gestion des transformateurs et utilisateurs.
